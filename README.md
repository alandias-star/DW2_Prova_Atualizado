### Paleta de Cores (Variáveis CSS)

- **`--paper` (`#FFFFFF`)**: Fundo da página e superfícies principais.
- **`--ink` (`#181A2A`)**: Texto principal e identidade da marca.
- **`--slate` (`#687280`)**: Textos secundários, descrições e metadados.
- **`--mist` (`#F3F4F6`)**: Superfícies suaves e fundos alternativos.
- **`--line` (`#E5E7EB`)**: Linhas de separação e bordas.
- **`--accent` (`#6D28D9`)**: Cor primária para botões, destaques e links.
- **`--price` (`#059669`)**: Destaque para preços e valores monetários.
- **`--star` (`#F59E0B`)**: Avaliações e classificações.

### Tipografia (Google Fonts)

- **Space Grotesk**: Utilizada em logotipos, títulos principais e preços.
- **Inter**: Utilizada no corpo do texto, navegação, botões e campos de formulário.

## 🚀 Recursos Implementados

- **HTML5 Semântico**: Estrutura organizada com tags como `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` e `<footer>`.
- **Layout Responsivo**: Grade de produtos construída com CSS Grid e Flexbox, adaptada para dispositivos móveis através de _media queries_.
- **Carrinho de Compras Funcional**: Adição de itens, controle de quantidade (incremento/decremento), remoção, cálculo dinâmico de subtotal, taxas de frete para São Paulo e finalização de pedidos.
- **Persistência de Dados**: Utilização de `localStorage` para manter os dados do carrinho e o tema selecionado mesmo após recarregar a página.
- **Alternância de Tema (Modo Claro / Escuro)**: Recurso interativo em JavaScript que alterna o esquema de cores globalmente.
